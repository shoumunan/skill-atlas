# Skill Atlas 使用手册

一句话：**技能的供给与运维层**。agent 在会话里搜、装、诊断、沉淀技能；你每周开一次面板，清收件箱、调供给。装什么都要过本地安全扫描，市场的评分与认证只是参考。

## 你是谁，从哪读起

- **会话里的 agent**：不用读这本手册。App 已把 `skill-atlas` 元技能挂到所有平台，agent 自己知道什么时候跑 `atlas search / install / simulate / new`。
- **每周开一次面板的人**：读下面四条工作流，够用一年。
- **技能少于 20 个、只用一个 AI 软件的人**：诚实说，Claude Code 原生的 `/plugin` 和 `~/.claude/skills` 就够了，暂时用不上本工具。
- **想把技能库分享给同事的人**：还没做（P2 边界），先用 GitSync 手动同步。

侧栏六项对应六个问题：**技能库**（我有什么）、**发现**（怎么获得）、**供给**（谁带哪些进场）、**收件箱**（有什么要裁决）、**创作**（怎么沉淀）、设置（长期配置）。

## 四条工作流

### ① 找并装上一个新技能（发现，⌘2）

1. 打开发现页。有链接就点「从链接或文件夹…」直接粘；没头绪就搜市场（skills.sh 全球 + SkillHub 国服），或逛官方精选与 SkillHub 热门榜。
2. 点条目右侧「安装…」。GitHub 型走克隆；SkillHub 型下载 zip 并安全解包（`..`、符号链接、穿链一律整包拒收）。
3. 安装 sheet 里勾选要装的技能与目标平台。装前安全扫描自动跑；**有关键级命中会强制进审阅页**，看完原文再决定。
4. 带「要密钥」标的技能装完还要按它的说明注册账号或配密钥。

**完成证据**：结果清单显示「已装好，Claude 里能用了」，技能库列表里能搜到它。
**失败分支**：市场没搜到 → 换关键词或直接粘 GitHub 链接；审阅页看不懂命中 → 别装，回网页看评测。

> agent 等价：`atlas search <词> --remote --source all --json` → 对 repoURL 非空的条目 `atlas install <repoURL>`。

### ② 给新项目配供给（供给，⌘3）

1. 打开供给页，左轨「项目」→「添加项目…」选中项目目录。
2. 点「套用场景包…」选一个场景包（没有就先点场景包行尾的管理按钮建一个，把该项目要用的技能拉进成员）。
3. 确认写盘 sheet（会列出排除哪些、保留哪些），确定。

**完成证据**：项目卡显示「已绑定『X』：N 个技能不进该目录会话的自动清单」；项目里多出 `.claude/settings.local.json`。App 关掉照样生效。
**失败分支**：绑错了 → 「解除绑定」一键恢复；全局清单太肥 → 左轨选 Claude，点「瘦身草案…」按使用次数分档，应用后账单头直接报前后 token。

> agent 等价：`atlas profile apply <场景名> --project <目录>`；`atlas slim --apply`。

### ③ 每周清一次收件箱（收件箱，⌘4）

1. 周一打开收件箱（侧栏徽标 = 待裁决数）。
2. 从「先处理这一件」的主任务卡开始：待审批点「审阅并批准…」，安全命中点「打开原文」看完再说，挂载问题进详情修，miss 点「开处方」改描述，可更新点「看更新…」看 diff。
3. 整理类（触发重叠、介绍不好找）可以「忽略」；安全关键、挡住使用的、待审批不能忽略，处理掉才消失。

**完成证据**：页面出现「一切安静」和上次裁决时间；徽标归零。
**失败分支**：忽略过的事项内容一变会自动回来，不用担心静音出事。

> agent 等价：`atlas doctor --json` 一次拿到全部九类事项。

### ④ 把流程沉淀成技能（创作，⌘5）

1. 创作页第 1 步输入技能名（可勾选带上剪贴板里刚复制的流程），点「建骨架」。
2. 回到你的 agent 会话说「把 <技能名> 的 SKILL.md 填完」——内容让 agent 写，触发三元组写在 description 前 250 字符内。
3. 第 2 步「开一个只装它的会话…」在隔离环境试跑（注意事项四条都列在卡片里）。
4. 第 3 步输入一句用户会说的话点「预演」，直到它排第一（绿勾）。排不到第一时按提示把关键词写进 description。
5. 改写描述两周后，收件箱会出回访卡对比前后命中。

**完成证据**：第 3 步绿勾「这句话能唤到它」；真实会话里说同样的话技能被触发。
**失败分支**：中途关掉 App 没关系，回来接着走（步进会恢复）；想换个想法点「换一个想法」，已建的技能留在库里。

> agent 等价：`atlas new <name>` → 填内容 → `atlas simulate "<场景句>"` → `atlas sandbox <name>`。

## 边界（明确不做 / 只做到哪）

- **不判断技能内容质量**。装前扫描只拦危险写法（`curl | sh`、路径穿越、可疑网络调用），好不好用要你自己试。
- **档位（三档供给）只对 Claude Code 生效**；其他平台按挂载二态供给。
- **不做跨机实时同步**。设置里的 Git 快照是手动的。
- **不管 MCP 服务器与子代理**，只管 Agent Skills（SKILL.md）。
- **市场排名与认证仅供参考**，SkillHub 的「已审核」不减免本地任何一道门。
- marketplace.json 市场仓库不用专门支持：它本身是 GitHub 仓库，粘链接就能装出里面全部技能。
