# Skill Atlas 使用手册

一句话：**帮你把技能管好，然后别烦你**。技能装了就能用；真出问题时，App 会在「检查」里用人话告诉你怎么了。

## 你是谁，从哪读起

- **会话里的 agent**：不用读。App 已把 `skill-atlas` 元技能挂到所有平台，agent 自己知道什么时候搜、装、诊断、沉淀。
- **你**：读下面四条，够用一年。
- **技能少于 20 个、只用一个 AI 软件的人**：诚实说，Claude Code 自带的 `/plugin` 和 `~/.claude/skills` 就够了，暂时用不上本工具。

侧栏四项，名字就是你会问的那句话：

| 页 | 你想问的 |
|---|---|
| **技能库** | 我有哪些技能 |
| **添加技能** | 我要多一个 |
| **检查** | 有什么要我处理吗 |
| 设置 | 长期配置 |

## 四条日常

### ① 装一个新技能（添加技能，⌘2）

1. 有链接就点「从链接或文件夹…」直接粘；没头绪就搜市场（skills.sh 全球 + SkillHub 国服），或看官方精选。
2. 点条目右侧「安装…」。装之前会自动扫一遍代码，**扫到危险写法会拦下来让你先看原文**。
3. 勾选要装到哪几个 AI 软件。带「要密钥」标记的技能，装完还得按它的说明去注册账号。

**成了的标志**：结果里写「已装好，Claude 里能用了」，技能库里能搜到它。

> agent 等价：`atlas search <词> --remote --source all --json` → `atlas install <repoURL>`

### ② 自己做一个技能（添加技能 → 自己做一个）

1. 起个名字，App 建好文件。
2. 回到你的 agent 会话说「把 <技能名> 的 SKILL.md 填完」——内容让 agent 写。
3. 想验证的话，在技能详情里试一句话，看它会不会被叫到。

**成了的标志**：真实会话里说那句话，技能被触发。

> agent 等价：`atlas new <name>` → 填内容 → `atlas simulate "<场景句>"`

### ③ 每隔一阵看一眼「检查」（⌘3）

页面顶部一张卡告诉你：**每次跟 Claude 说话，它都要先读一遍你所有技能的简介，这份简介现在多长**。技能攒多了这个数会涨，点「挑出不用的」按使用次数排一遍，逐个决定关不关。

下面是要你处理的事，只有四类：

- **等你确认**：会话里的 agent 想装个东西，但扫出了危险写法
- **可能不安全**：某个技能里有危险写法
- **装了用不了**：技能和 AI 软件之间的连接断了
- **叫不动**：你说的话它本该接住却没接

**成了的标志**：页面显示「没有要处理的事」。

> agent 等价：`atlas doctor --json`

### ④ 让某个技能少占位置（技能库 → 选中技能 → 怎么用它）

每个技能有三种用法：

- **自动**：Claude 会自己想到用它
- **点名才用**：你打 `/名字` 才会用，**不占开场的篇幅**
- **关掉**：完全不用

不常用但偶尔要的技能，设成「点名才用」最划算：随时能叫，平时不花钱。

> agent 等价：`atlas slim --apply`

## 边界

- **不判断技能好不好用**。装前扫描只拦危险写法（`curl | sh`、路径穿越、可疑网络调用），内容质量得你自己试。
- **三种用法只对 Claude Code 生效**。其他软件只有装 / 不装两种。
- **不做跨机实时同步**。设置里的 Git 快照是手动的。
- **只管 Agent Skills（SKILL.md）**，不管 MCP 服务器和子代理。
- **市场的评分和认证只是参考**，不减免本地的任何一道检查。
- 给不同项目配不同技能（场景包）在设置 → 进阶里，属于少数人才需要的功能。
