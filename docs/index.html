Skill Atlas 装好就能用

把技能管好，然后别烦你

本地 macOS 应用，四个页面：技能库、添加技能、检查、设置。技能装了就能用，真出问题时到「检查」看一眼。终端里的 agent 用 atlas 自己搜、装、诊断。装什么都先过一遍本地安全扫描。

下载 Skill Atlas

macOS 14+ · Apple 芯片 · 未公证，首次请右键打开

发现与直装

聚合搜 skills.sh 与 SkillHub，官方精选一键装。zip 包安全解包，装前扫描一道不少。

少占位置

技能攒多了，每次对话都要先读一遍所有简介。不常用的设成「点名才用」，随时能叫，平时不花钱。

出事才出声

等你确认、可能不安全、装了用不了、叫不动——只有这四类会来找你。平时它是安静的。
